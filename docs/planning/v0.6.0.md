## Theme rationale

The HOS oversight loop (worker/overseer, contract, review chain, second review, panel, red-team) is already stack-agnostic. What is Django-specific is the **deterministic signal layer**: on an all-`.astro`/`.ts`/`.js` changeset every `PY_FILES`-gated validator skips, so ~half the 12 scoring dimensions go dark, and there is no `packs/astro` giving the base team JS/Astro idioms. v0.6.0 closes that gap with a **two-layer pack** — a generic `node` pack (reusable for future Next/SvelteKit) plus an `astro` pack layered on it via `pack.toml requires = ["node"]`.

---

## Epic-level acceptance criteria

- **AC-1 (signal density):** on an all-JS/TS changeset, ≥10 of 12 scoring dimensions emit real (non-skipped) signal.
- **AC-2 (Python regression):** Python-only changesets score byte-identical to pre-change `main`.
- **AC-3 (schema stability):** new validators emit the shared `schema.py` envelope; weights/thresholds unchanged or logged in `DECISIONS.md`.
- **AC-4 (gates):** eslint + `astro check`/`tsc` run and block in an Astro project; every gate no-ops cleanly on non-JS projects.
- **AC-5 (pack install):** `hos_install.sh --pack astro` resolves + injects `node`; `--pack node` installs standalone.
- **AC-6 (dogfood):** a field report from a real Astro project exists before close.
  **Not met at ship** — no dogfood field report or Tutelare-specific findings doc exists.
  Human decision 2026-08-12 (#1330): ship with AC-6 outstanding rather than block the
  release on it. If a Tutelare field report happens later, file it as a standalone
  issue against whatever milestone is active then — it does not reopen v0.6.0.

## Build steps (see #1029 for the full per-step spec)

### Foundation
- **S1** — language-aware `JS_FILES` routing in `run_validators.sh` (HIGH; root dependency for all validators)
- **S2** — JS toolchain discovery helper (`ensure_node` analog to `ensure_venv.sh`)
- **S3** — installer `pack.toml requires` resolution (HIGH; **net-new** — no `requires` parsing exists today)

### JS/TS validators
- **S4** complexity · **S5** function-metrics · **S6** static-analysis · **S7** hallucination + `package.json` existence check · **S8** RN JS calibration · **S9** N+1 analog

### Gates
- **S10** lint (eslint) · **S11** type (`astro check`/`tsc`) · **S12** new `astro_check.sh`

### Pack agent depth
- **S13-S15** `packs/node/` (scaffold+core, review lenses, test+UI)
- **S16-S18** `packs/astro/` (scaffold+core, review lenses, test+UI)

### Validation & docs
- **S19** docs (+ `portability_check` if a gap is found) · **S20** dogfood field report (last) — target: **Tutelare** (tutelare.ai, a fresh/greenfield Astro site); must also measure the mixed-changeset dimension double-counting from ADR §4 (realized vs `WEIGHTS`)

## Open decisions (resolved during implementation; table below was never updated to say so — reconciled 2026-08-12 against the actual shipped code, see `DECISIONS.md`)

| ID | Decision | Resolution actually shipped |
|----|----------|------------------------------|
| D1 | Node baseline | Resolve from consumer toolchain, never force-install (`lib/detect_stack.sh`, floor Node ≥22, fail-hard preflight). `DECISIONS.md:531,536`. |
| D2 | JS tool provisioning | Discover-only: `node_modules/.bin` → `npx --no-install` probe → PATH. Never installs, never vendors. `lib/resolve_node_tool.sh`. `DECISIONS.md:536`. |
| D3 | Installer `requires` scope | Widened: DFS transitive closure over pack `requires` (`hos_install.sh` `_pack_requires`/`_pack_closure_visit`). `config.sh PACK=` stays single-value by design. `DECISIONS.md:549-550`. |
| D4 | JS complexity tool | Neither escomplex nor eslint's rule — custom tree-sitter AST walker (`complexity_metrics_js.py`). `DECISIONS.md:539`. |
| D5 | JS/TS AST lib | `tree-sitter` (`tree_sitter_typescript`); `.astro` frontmatter/`<script>` extracted via regex fence scan (`function_metrics_js.py`). `DECISIONS.md:539`. |
| D6 | Static-analysis engine | semgrep, vendored ruleset, sole engine for JS (not additive like Python/bandit). `static_analysis_js.py`. `DECISIONS.md:531`. |
| D7 | RN nesting calibration | Provisional — reuses Python's Dai et al. weights, explicitly flagged `"provisional-js-reuses-python-weights"` in output. `rn_calculator_js.py`. `DECISIONS.md:539`. |
| D8 | N+1 analog | fetch/await-in-loop heuristic, marked provisional pending dogfood data. `n1_detector_js.py`. `DECISIONS.md:539`. |
| D9 | `astro_check.sh` mechanism | `astro sync` then `astro check` (not a build). `gates/astro_check.sh`. `DECISIONS.md:539`. |
| D10 | Where JS validators live | Shared `validators/` dir, language-gated by file extension (the recommended option) — not pack-discovered. `run_validators.sh` `JS_FILES[]` routing. `DECISIONS.md:538`. |
